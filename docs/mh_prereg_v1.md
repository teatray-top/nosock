## 3. 헤드 S (15분)
- 결정 시각 t: 09:16~15:00의 매 분봉 종가 시점(피처에 최소 15봉 필요, 청산이 15:20 단일가 접수 전에 끝나도록).
- 진입 = t+1 봉 시가 + 5원, 청산 = t+16 봉 시가 − 5원(15봉 보유). 라벨 y_S = (매도대금 − 매도수수료 − 매수대금 − 매수수수료) / (매수대금 + 매수수수료).
- 피처(모두 ≤ t 정보, 15개 고정): r1, r5, r15, r30, r60(분 수익률), 시가 대비 수익률, 당일 범위 내 위치(0~1), 최근 5분 거래량 / 당일 분평균 거래량, 최근 15분 실현변동성, 분(09:16=0부터 정수), 요일, 전일 수익률, 전일 기준 5일·20일 수익률, 전일 기준 20일 변동성, 종목 ID(0/1).
- 모델: LightGBM regression(l2). 파라미터 고정: num_leaves 31, learning_rate 0.05, n_estimators 400, min_data_in_leaf 200, feature_fraction 0.8, bagging_fraction 0.8, bagging_freq 1, lambda_l2 1.0, seed = {0,1,2,3,4}, 예측 = 5시드 평균. 조기 종료 없음(검증을 임계값 선택에만 사용).
- 임계값 τ: 검증 구간 예측값의 상위 {1%, 2%, 5%} 분위 중 검증 비용 후 평균수익이 최대이고 거래 ≥100건인 것. 추가로 "예측 > 0" 규칙도 고정 보고. 시험 구간에서는 선택된 τ만 1회 적용.
- 폴드(연 단위 walk-forward, 날짜 고정):
  - F1 학습 2022-11-23~2023-12-29, 검증 2024-01-02~2024-03-29, 시험 2024-04-01~2024-12-30
  - F2 학습 2022-11-23~2024-09-30, 검증 2024-10-01~2024-12-30, 시험 2025-01-02~2025-12-30
  - F3 학습 2022-11-23~2025-09-30, 검증 2025-10-01~2025-12-30, 시험 2026-01-02~2026-11-05
  - 퍼지: 라벨 청산 시각이 다음 구간 시작 이후인 표본 제외(15분이라 사실상 없음) + 구간 경계 1거래일 엠바고.
- 원장 규칙(S 단독): 종목당 동시 1포지션, 신호 시 단타 버킷 현금으로 정수 주 매수, 15봉 뒤 매도, 당일 버킷 손실 −2% 도달 시 당일 중단.

## 4. 헤드 L (60거래일)
- 결정 d일 종가. 진입 d+1 시가 + 5원·A, 청산 d+61 시가 − 5원·A. 라벨 y_L = dip_entry_bt v4 `trade()`와 동일 계산(실제 주, 원 절사 수수료, 분배 근사 A[x]/A[d]).
- 피처(≤ d, 14개 고정): r1, r5, r20, r60, r120, r250, 60일·250일 고점 대비 낙폭, 20일 변동성, 20일 거래량 / 120일 거래량, C/MA20, C/MA60, C/MA120, 월, 종목 ID.
- 모델·시드·파라미터: 헤드 S와 동일(min_data_in_leaf 50으로만 조정, 일봉 표본 수 때문).
- 임계값: 검증 예측 상위 {10%, 20%, 30%} 분위 중 검증 비용 후 평균수익 최대·거래 ≥30건, "예측 > 0"도 보고.
- 폴드(연 단위): 시험연도 y ∈ {2015, …, 2026}, 학습 2002-10-14~(y−2)-12-31, 검증 (y−1)-01-01~(y−1)-12-31, 시험 y-01-01~y-12-31(2026은 11-05까지). 229200은 2015-10-01부터 포함. 퍼지: 청산일(d+61)이 다음 구간 시작 이후인 표본 제외 + 5거래일 엠바고.
- 원장 규칙(L 단독): 종목당 동시 1포지션, 신호 시 중장기 버킷 현금으로 정수 주 매수(1주 미만이면 현금 보유), 60거래일 뒤 매도.
