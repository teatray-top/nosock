## 12-2. v1.3 수정 (bill 13:10 반영, 자료 결측 처리)
- **결측 ≠ 거래량 0.** 청산 예정 봉(t+17분)이 자료에 없으면 지연 청산으로 옮기지 않고 **exit_unknown**(진입 시각·가격 보존, 라벨 불가). 지연 규칙은 관측된 거래량 0 봉에만 적용하며, 지연 탐색 중 결측 분을 만나도 exit_unknown.
- **접두 구간 완전성**: 일중 시가·누적 고저·누적 거래량 피처가 있으므로 세션 개장(09:01, late_open_special이면 10:01)부터 t까지 모든 분봉이 있어야 피처를 계산한다. 아니면 feature_gap.
- **결정 봉 결측**: 고정 60시각(10:05~15:00)을 매일 순회해 결정 봉이 없으면 decision_missing 행을 남긴다(하루 60행 고정, 가용성 분모 보존).
- 원장(bill 13:16 정정): **exit_unknown 진입은 익일 청산하지 않는다**(체결 경로 창작 금지). 포지션을 "불확실"로 표시해 열어 둔 채 확정 종가로 평가만 하고(현금 잠금, 실현손익·금고 없음), 건수·평가액을 `S_exit_unknown_open`·`uncertain_open_value`로 보고한다. 익일 규칙은 15:19까지 **관측된 거래량 0**으로 미청산이 확인된 경우에만 적용. 익일 청산 가정은 별도 시나리오 원장(`*_unknown_nextday_scenario`)으로만 분리 보고. 미래 결측을 이유로 진입을 생략하지 않는다(미래 정보 사용 금지).
- 수집기: 실패 응답(HTTPError)의 허용목록 헤더(retry-after, x-ratelimit-*, x-request-id, date, content-type)도 attempts.jsonl 실패 행에 보존(bill 13:15).
- 현금 기준선 원장은 입금을 현금으로 보유한다(총자산 = 누적 입금).
- **적격 규칙(자료 단계 확정, 테이블 `s_eligible`/`l_eligible`)**: S 학습·검증 표본 = flag ∈ {ok, delayed} ∧ 라벨 유한 ∧ 피처 16개 유한 ∧ 그날 원문 내용 충돌 0 ∧ 그날 incomplete 아님. L = 미완료 아님 ∧ 라벨 유한 ∧ 피처 15개 유한. 원장은 원문 충돌·incomplete 날에는 S 신규 진입을 하지 않고(S_day_excluded 보고) 예정 청산·이월 청산은 수행한다.
- **벽시계 상한 집행(bill 13:12·13:23)**: monotonic 마감시각, 적합 중 LightGBM 콜백으로 중단, 적합 전·예측 전 검사, 별도 감시 스레드가 **마감 즉시(유예 0초)** 프로세스 종료(코드 3) → 선언한 2시간을 넘기지 않음. selftest에 0.3초 마감 중단과 감시 스레드 종료 확인 포함.
