## 3. 비용 구조가 결정하는 것
- 미장 $7 포지션: 최소 수수료 $0.01 = 편도 0.14% → 왕복 0.28% + SEC + 스프레드. $50에서 0.2%+스프레드. 단타 다리에 구조적으로 불리.
- 국장 개별주: 수수료 0.015%×2 + 매도 거래세 0.15~0.2% → 왕복 ≥0.18%.
- **국장 지수 ETF: 수수료 0.03% 왕복, 거래세 없음, 틱 5원(KODEX200 8만원대 0.006%, 레버리지 1~2만원대 0.03~0.05%), 호가 두터움** → 왕복 0.04~0.1%. 측정한 어떤 단타 후보의 비용보다 3~6배 싸다. 단타 다리를 둔다면 첫 측정 대상은 여기다. 1분봉은 토스가 2022-11-23부터 제공 → 069500/122630/252670/229200 백필 약 6천 요청(10분 내)으로 확보 가능(백필 잡과 rps 공유, 승인 후 시작).
- 1만원/일 리필 규모에서 국장 ETF 1주(KODEX200 8만원대)는 8일치, 레버리지(1~2만원대)는 1~2일치.

## 4. 구조 후보 (나열, 하나로 고정하지 않음)
| | A. 기간별 헤드 지도학습 | B. 단일 시퀀스 멀티태스크 | C. 기간 선택 RL | D. 규칙 묶음 + 배분기 |
|---|---|---|---|---|
| 모델 | 공통 피처 → LightGBM 헤드 ×기간(15m/60m/1d/5d/20d/60d/120d), 출력 = 비용 후 초과수익 예측 | 1분봉+일봉 시퀀스 → 공유 인코더 → 기간별 출력 | 행동 = {단타 매수, 스윙 매수, 장기 매수, 보유, 청산}, 보상 = 공유 현금 원장 비용 후 손익 | 측정 통과 규칙만 조합, 학습 없음 |
| 장점 | 빠름(CPU 분 단위), 해석 가능, 기간별로 독립 검증·제거 가능 | 표현력 | 배분까지 한 번에 | 가장 투명, 기준선 |
| 단점 | 기간 간 상호작용은 배분기에 맡김 | ~500일 데이터로 과적합 위험, GPU 시간 | 지금까지 RL은 시드 분산·거의 안 거래로 수렴 | 통과 규칙이 현재 0개 |
| 제안 | **1차** | A 통과 후 | A·B 뒤 | A의 기준선 |

추천: A를 D 기준선과 함께 먼저. 핵심은 모델이 "언제 어느 기간으로 들어갈지"를 비용 후 기대값으로 고르는 것이며, 단타 헤드가 검증에서 음수면 배분기가 단타 비중 0을 택하는 것도 결과로 인정한다. 단타 우위를 모델이 만들어내는 것이 아니라 있는지 측정하는 것이다.

## 7. 자금·위험 원장 (통합의 핵심)
