# 단타머신 전체 점검 (2026-11-04)

검토 방식: 5개 영역(체결·회계 / 데이터 / 판독기 / 도비·백테스트 / 개념)을 각각 검토한 뒤, 다른 검토자가 모든 항목을 코드·데이터·외부 자료로 반박 시도. 68개 항목 중 확인 62, 반박 5, 미확정 1. 아래는 확인된 것만 심각도 순.

## 0. 총평

- 코드의 뼈대(체결 시점, 피처 인과성, 금고 회계, 무작위 비교 설계)는 맞다. 누출은 없다.
- 그러나 **지금까지의 결과 숫자는 거의 전부 신뢰할 수 없다.** 한국은 데이터 선택 편향 위에서 측정됐고, 도비 5시드는 한 종목 한 거래였고, 미국은 상위 3일과 사후 선택에 기대고 있다.
- 개념 자체에 두 개의 외부 충돌이 있다: (1) 2026-07 시행 동전주 상폐 규정이 우리 유니버스를 정면으로 겨눈다. (2) 미국 7달러 시드는 최소수수료·소수점 주문 규칙(시장가만, 정규장 마감 1시간 전까지)과 맞지 않는다.

### 1-4. 미국 7달러 시드의 실행 가능성 — major (일부 미확인)

### 1-6. 체결 모델의 비대칭 낙관 — major
- 매수는 `has & O>0`을 요구하지만 **매도는 거래 없는 봉에서도 ffill 종가 −1틱으로 전량 체결**(`sim.py:153-157`). 매도에 거래량 상한도 없음.
- KR 5m 후보군: 체결봉의 6.6%가 무거래 봉, 강제청산봉(71)은 7.1%. 판독기 라벨은 청산의 **20.1%**가 무거래 봉(14.3% ffill 종가, 5.8% 거래량 0 봉 시가). US는 0.4%로 KR 전용.
- KR 60m `exit_bar=6`은 데이터가 없는 봉(has 0%) → 모든 강제청산이 봉5 종가로 체결.
- `run_days`는 `pi = cash − cap`으로 전량 청산을 가정(검사 없음). 매도에 has를 넣는 순간 미청산 주식이 사라지는 숨은 결합.
- 수정: 매도도 `has` 요구, 불가 시 다음 봉 이월, 종료 시 마크투마켓. 하한가 잠김(`o ≤ pc·0.705`) 매도 금지.

### 1-7. 라벨 스탑 ≠ 백테스트 스탑 — major
- 라벨(`reader.py:34-36`): 진입봉 포함 구간 **저가**가 −6% 터치면 **정확히 −6%에 체결**, 슬리피지 0.
- 백테스트(`us_bt.py:42` → `sim.py:153`): **종가**가 −6% 이하일 때 **다음 봉 시가 −1틱**.
- 라벨 스탑 중 종가 기준으로도 발동하는 비율 US 75% / KR 69%; 갭 관통(최저가 ≤ 스탑가×0.98) US 29% / KR 40%. 진입봉 안에서 발동한 스탑 231/6573은 Env가 재현 불가.

### 1-9. 평가 방법론 — major
- 검증셋 없음. h/STOP/RANK/epoch/임계값 전부 테스트 창(back0)에서 선택. runs/에 back0 전용 json 20개.
- `best_per_bar`는 매 봉 36봉 거래를 중복 집계(541픽 중 종목 91개). top-k는 사후 분위수. AUC 샘플 152만이지만 유효 표본은 일수(14).
- 라벨 h=36 중 실제 36봉 지평은 53%, 7%는 ≤5봉(장 마감 절단) → `tb`가 지평 길이 대리변수가 되어 auc_stop 0.92를 부풀릴 수 있음. `b+1 > entry_last` 샘플도 학습·평가에 포함.
- 라벨이 절대수익 → 시장·레짐 성분 학습(횡단면 평균이 분산 8% 설명, 일별 기저승률 0.13~0.60). randpick이 평가에서는 상쇄하지만 학습 신호는 오염.
- 14일 창 검정력: +0.5%/일 엣지를 t=2로 잡으려면 σ 7%/일(KR) 기준 ~780거래일, US σ 2~3% 기준 64~144일. 지금 42일.
- randpick 난수 생성기가 전역 1개 → 셀 순서에 따라 결과 변함(셀 단위 재현 불가). 일별 rows 미저장.
- 학습 표본의 74%가 실매매 불가 종목(elig·cheap 미적용).
- trades 집계가 매수·매도 각 1 → 보고된 "거래/일"은 왕복의 2배.

### 1-10. 리필 규칙 — major
- `summary.net = vault + R − refill`로 총현금흐름은 보임(장점). 그러나 **누적 투입 상한·중단 조건 없음.** p1s1: 19일에 refill 19,838원.
- 이기는 날은 50%만 복리, 지는 날은 100% 사용자 부담 — 의도된 비대칭이지만 금고 잔액이 손실을 심리적으로 가림.
- 제안: 누적 refill 상한(예: 20일치) 도달 시 자동 중단·재검증. 월간 net을 1차 지표로.

### 1-11. 한국 개념 자체 — critical
- 적격·저가 종목의 09:05→14:55 평균 로그수익 **−0.31%/일**(std 4.4%), 세 14일 구간 모두 음수. 전 종목 60m 2년 평균도 −0.245%/일 → 음의 일중 드리프트는 구조적.
- 왕복 비용 0.37~0.43%(수수료 0.03 + 세금 0.20 + 2틱 0.14~0.20). 거래당 ≥0.4% 총수익 엣지가 필요.
- 1만원 시드에서 거래당 기대이익(+1% = 75원)과 비용(30~40원)이 같은 자릿수 → 노이즈 지배.

- 방향: 롱온리 일중 추종을 버리고 (a) 시장중립(횡단면) 라벨로 종목선택만 측정, (b) 하루 ≤1회·1~3일 보유 허용, (c) 미국에서 엣지 확인될 때까지 KR는 페이퍼.

## 3. 잘 된 것

- 체결 시점이 양방향 일관(결정 봉 종가 확인 → 다음 봉 시가 ±1틱). 미래 봉 참조 없음.
- 피처 13종 전부 봉 b까지의 값만 사용, 학습된 정규화 없음 → train/test 누출 없음. 시간순 분할.
- 금고 회계 정확: `vault += share·pi, R += (1−share)·pi`, 손실은 R부터, R 음수 불가, `net = vault + R − refill`.
- 매수 체결은 보수적(has, 시가>0, 상한가 근접 배제, 거래량 20% 상한, KR 정수주/US 최소금액).
- same-timing randpick 베이스라인 설계가 올바름 — 시드만 늘리면 경험분포 검정으로 바로 쓸 수 있음.
- us_bt `held` 로직에 KeyError·stale 경로 없음. 체크포인트 없으면 즉시 중단(조용히 잘못된 모델 쓰는 경로 없음).
- 보상이 cap 대비 %로 정규화, GAE 종단 처리 정상, 마스크 일관.
- 라벨 생성+추론이 CPU 5초 → 수정 실험 비용 낮음.

## 4. 수정 순서 (제안)

### 4-1. 데이터 (결과를 바꾸는 것부터)
1. KR 학습·백테스트를 `panelall*`로 전환, 가격 필터는 시점별 `pc·MIN_SHARES ≤ cap`만. `universe.csv` 수집 중단.
2. `pc`·전일 거래대금을 `data/1d` 공식 종가·거래량에서 조인.
3. 첫 봉 `has`를 가격 존재로 판정(`~isnan(O)`), 거래량 0은 체결 조건에서만.
4. `NBARS` 72/6, KR 60m exit 재정의, 지연개장일 세션 테이블, 캐시 무효화(mtime), `archive` 접두어, US fetch 갱신 로직.
5. US 리스팅 필터 단어 경계 + SPAC 제외, 60m 730일 오류 종목은 start/end 재시도.
6. 예약 작업 등록 확인(사용자), collect.py try/except·결손 알림.

### 4-2. 체결·회계
7. `fill_buy/fill_sell` 헬퍼 하나로 라벨과 Env 통일(SLIP 포함). 스탑 정의 통일(종가 판정 → 다음 시가, 또는 Env에 봉내 스탑 추가).
8. 매도에 `has` 요구 + 이월 + 종료 시 마크투마켓, 하한가 잠김 매도 금지, 매도 거래량 상한.
9. US 수수료에 고정비 항 `max(rate·notional, min_fee)` + SEC fee(공식표 확인 후), US 소수점 마감 1시간 전 청산(`EXIT_BAR` ≤ 66), 환전 비용 항.
10. 시장별 설정(비용·틱·봉수·최소주문·시드)을 한 곳(`MarketSpec`)에. `DEPOSIT` 통화 분리.
11. 누적 refill 상한·중단 조건.
12. trades → fills/round_trips 분리.

### 4-3. 라벨·학습
13. 시장중립 라벨(같은 (일,봉) 횡단면 중앙값 차감) 추가, 절대 드리프트는 별도 헤드.
14. 지평 길이 `(x−e)/h` 피처 또는 h 미만 샘플 제외, `e ≤ entry_last` 필터.
15. 학습 표본 = 매수 가능 집합(`buyable` 마스크 하나를 reader·Env가 공유).
16. 회귀 헤드 제거 또는 E[r] 점수로 활용.

### 4-4. 평가 프로토콜 (수용 기준)
17. 설정 동결(h/STOP/RANK/thr). train 끝 N일을 검증으로 떼어 거기서만 선택.
18. 워크포워드 ≥6폴드(14일×6 = 84일/시장). 폴드별 randpick ≥200시드 경험분포, 판독기 ≥95백분위인 폴드 ≥5/6.
19. 일별 rows 저장, 폴드 합산 paired bootstrap(1e4) 95% CI가 0 배제. 상위 k일 제외 합·중앙값·무거래일 수 병기.
20. 비용 ×1.5, SLIP 2틱, 최소수수료 적용에서도 유지.
21. 통과 후 ≥60거래일 페이퍼(시뮬 체결가 vs 실제 호가 차이 측정) → 1만원 실거래.

### 4-5. 운영
22. 주문은 공식 Open API로 설계, tossctl은 조회·검증용. US 정규장 23:30~06:00 무인 운영 규칙(마감 전 강제 청산, 장애 시 포지션 확인), 데이마켓 사용 금지(레짐 불일치).
23. 뉴스·테마는 (일, 종목) 메타 배열로 판독기 입력에 concat(장 시작 전 확정값만).

## 5. 사용자가 정해야 할 것

1. KR 유니버스 하한: 1,000원 이상으로 올릴지(상폐 규정 회피), 아니면 `MIN_SHARES` 규칙을 금액 기준으로 바꿔 2,000~10,000원대로 갈지.
2. 보유 기간: 당일 청산 고정 유지 vs 1~3일 보유 허용(KR 비용 구조상 필요).
3. 미국 시드: 7달러 소수점 유지(최소수수료·시장가·마감 1시간 전 제약 감수) vs 일 단위로 한 시장 100%(x∈{0,1})로 단순화.
